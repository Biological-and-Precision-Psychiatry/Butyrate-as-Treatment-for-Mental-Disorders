## Overview

This repository contains the publicly shareable data and R code used for the
systematic review and meta-analysis.

The project includes:

- 29 clinical studies (PICO 2)
- 117 preclinical controlled animal studies (PICO 3)

The repository documents data preparation, meta-analyses, sensitivity
analyses, tables, and figures presented in the manuscript and supplementary
material.

All analyses were conducted in R.

---

## Analysis conventions

Unless otherwise stated, the following conventions apply across the analysis
reports:

- Primary meta-analyses include only records marked `include == 1`.

- When several follow-up measurements are available for the same study and
  outcome within the relevant disease/model and intervention grouping, the
  measurement closest to the intervention duration is selected.

- Outcome directions are harmonised using the `direction` variable before
  effect sizes are calculated. The direction and interpretation of the
  behavioral animal tests are described in Supplementary Table S5 of the
  supplementary material accompanying the article.

- For PICO 3, the primary behavioral analyses presented in the main manuscript
  exclude observations for which outcome values were digitised from figures
  (`extraction.source == "graph_extracted_data"`).

- Absolute SMD thresholds are applied only in explicitly labelled sensitivity
  analyses. These analyses assess whether the pooled results are driven by
  very large effect estimates; no absolute SMD threshold is applied to the
  unrestricted primary dataset.

- The influence analyses are leave-one-effect-out analyses: one effect
  estimate, rather than necessarily one entire study, is removed in each
  iteration. An asterisk identifies study labels that occur more than once
  within the same outcome category, for example when a study contributes
  several animal cohorts or populations with the same outcome. In most cases,
  however, removing one effect estimate is equivalent to removing one study.

## Repository structure

### Data

- `data_raw/`  
  Source data extracted from the included studies. These files form the
  starting point for the reproducible PICO 2 and PICO 3 workflows.

- `data_derived/`  
  Analysis-ready datasets generated by the data-preparation reports. These
  files include validated, transformed, imputed, or otherwise processed data
  used by the subsequent analysis reports.

- `data_ipd/`  
  Directory associated with individual-level data received directly from
  study authors for selected PICO 3 studies. The original individual-level
  data are not publicly shared. Summary statistics derived from these data
  have been incorporated into the shared dataset.

### Functions and outputs

- `functions/`  
  Custom R functions used for data import, data processing, meta-analysis,
  formatting, and plotting.

- `figures/`  
  Directory used for temporary standalone plot output when selected plotting
  chunks are run interactively in RStudio. Because multiple plotting chunks may
  write to the same test filename, these files represent only the most recently
  run plot and are not intended as the primary figure archive. The complete set
  of figures should be accessed through the rendered `.html` reports.

- `results/`  
  Directory for derived analysis results and exported summary files.

### PICO 2 reports

- `reports_pico2/`  
  R Markdown reports for the clinical analyses.

  - `00_run_all.Rmd`  
    Main entry point for PICO 2. Renders the PICO 2 reports in the required
    order and stops if one of the reports fails.

  - `10_prepare_data.Rmd`  
    Imports and validates the clinical source data and generates the derived
    PICO 2 datasets used in the subsequent analyses.

  - `21_overview_forest_plots.Rmd`  
    Produces overview forest plots used to inspect the prepared clinical
    dataset and the available effect estimates.

  - `30_manus_forest_plots.Rmd`  
    Produces the principal PICO 2 forest plots used in the manuscript and
    related sensitivity analyses.

  - `32_manus_funnel_plots.Rmd`  
    Produces funnel plots and reports small-study-effect tests where the
    number of available effect estimates is sufficient.

  - `35_table_1.Rmd`  
    Produces summary tables and associated forest plots for the clinical
    analyses.

  - `36_leave1out.Rmd`  
    Performs leave-one-effect-out influence analyses for the relevant
    clinical meta-analyses.

### PICO 3 reports

- `reports_pico3/`  
  R Markdown reports for the preclinical animal-study analyses.

  - `00_run_all.Rmd`  
    Main entry point for the publicly reproducible PICO 3 workflow. Renders
    the PICO 3 reports in the required order and stops if one of the reports
    fails. The restricted individual-level-data report is intentionally not
    included.

  - `10_prepare_data.Rmd`  
    Imports and validates the preclinical source data, converts reported
    standard errors to standard deviations where required, applies the
    documented imputations, combines relevant intervention arms, and
    generates the derived PICO 3 datasets.

  - `21_overview_forest_plots.Rmd`  
    Produces diagnostic overview forest plots showing the source data,
    the data after conversion and imputation, and the final analytic data
    after relevant intervention arms have been combined.

  - `30_manus_forest_plots.Rmd`  
    Produces the principal behavioral forest plots used in the
    manuscript, including analyses based on all eligible data and analyses
    excluding graph-extracted observations.

  - `32_manus_funnel_plots.Rmd`  
    Produces behavioral and biomarker funnel plots and reports small-study-
    effect tests where the number of effect estimates meets the specified
    threshold. Results are shown both with and without graph-extracted data.

  - `35_table_1.Rmd`  
    Produces summary tables and corresponding forest plots for behavioral
    and biomarker outcomes, including analyses stratified by the number of
    available effect estimates and analyses excluding graph-extracted data.

  - `36_leave1out.Rmd`  
    Performs leave-one-effect-out influence analyses for behavioral outcome
    categories. The report includes analyses with and without an absolute
    SMD restriction and analyses with and without graph-extracted data.

  - `41_ipd_analyses.Rmd`  
    Documents the analyses of individual-level data received from study
    authors. The original individual-level data are not included in the
    public repository, so this report cannot be reproduced without access to
    the restricted data. Summary statistics derived from these analyses were
    incorporated into the shared PICO 3 source data.

Rendered `.html` files and associated `_files/` directories may be present
alongside the `.Rmd` source files. The `.Rmd` files are the authoritative
analysis scripts; the HTML files provide rendered snapshots of their output.

## Reproducibility

To reproduce the publicly available analyses:

1. Clone the repository.
2. Open `Butyrate-as-Treatment-for-Mental-Disorders.Rproj` in RStudio.
3. Open the relevant entry-point report:
   - `reports_pico2/00_run_all.Rmd`
   - `reports_pico3/00_run_all.Rmd`
4. Click **Knit** in RStudio.
5. Open the generated `.html` files to inspect the results and figures.

The entry-point reports render the associated analysis reports in the required
order and stop if one of them fails.

Clicking **Knit** is the intended reproducibility workflow. Running
`rmarkdown::render()` directly from an already interactive RStudio Console is
not recommended, because selected plotting functions use interactive execution
to generate temporary standalone test figures. In that situation, plot output
may be written to `figures/` rather than embedded correctly in the rendered
HTML reports.

All data required for the publicly reproducible analyses are included in the
repository. Original individual-level data received from study authors are not
publicly available, but the derived summary statistics used in the shared
analyses are included.

## Notes
- PICO 2 and PICO 3 are implemented as separate analysis workflows.
- Each PICO has a dedicated entry point named `00_run_all.Rmd`.
- Data-preparation reports must be rendered before reports that depend on the
  derived datasets.
- Analysis reports are designed to run from a clean R session.
- Report-specific figures are generated during R Markdown rendering.
- Intermediate datasets are written to `data_derived/`.
- The individual-level-data report is retained to document the analytical
  workflow but is not part of the publicly reproducible pipeline.
- The preprocessing steps required for the publicly reproducible analyses are
  implemented and documented in the repository. Summary statistics derived
  from restricted individual-level data are incorporated into the shared
  PICO 3 source data.
- Figures are primarily intended to be viewed in the rendered `.html` reports.
  When plotting chunks are run interactively, selected functions may also write
  a temporary standalone figure to `figures/`. To obtain a specific standalone
  plot, run the corresponding plotting chunk individually; later plotting
  chunks may overwrite the same test file.
